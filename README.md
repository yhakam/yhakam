### Aviation Risk V2 — Détection d'anomalies de vol
Score de risque explicable basé sur des règles physiques du vol + Isolation Forest.  
98,1% d'accord entre les deux approches sur 9 500 vols analysés en temps réel via l'API OpenSky.
